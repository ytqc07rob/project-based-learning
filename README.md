# Contributing Guidelines

Thank you for considering contributing to Project-Based Learning!

## How to Contribute

1. Fork the repository.
2. Add your project tutorial under the appropriate programming language category in `README.md`.
3. Follow the existing link format:
   - `[Project Name](url)` - Short description of what the tutorial teaches.
4. Ensure the tutorial is free, comprehensive, and focused on building a complete project.
5. Create a pull request with a descriptive title.

## Guidelines for Submissions

- **Quality**: Links must point to high-quality, up-to-date tutorials or courses.
- **Categorization**: Place tutorials under the most relevant programming language or domain (e.g., Python, Data Engineering, Web Development).
- **Format**: Keep descriptions concise and clearly state the technologies used.
- **Working Links**: Double-check that your links are valid and publicly accessible.

Thank you for helping make project-based learning accessible to everyone!
