# Project-Based Learning

A list of programming tutorials in which aspiring software developers learn how to build an application from scratch. These tutorials are divided into different primary programming languages. Some tutorials also have videos and interactive challenges.

*Note that this list is not exhaustive and is meant to be a starting point for your own research.*

## Table of Contents

- [C/C++](#cc)
- [Python](#python)
- [JavaScript](#javascript)
- [Java](#java)
- [Go](#go)
- [Rust](#rust)
- [Ruby](#ruby)

## C/C++

- [Build a Compiler](https://github.com/rui314/chibicc) - A small C compiler
- [Build a Text Editor](https://viewsourcecode.org/snaptoken/kilo/) - A text editor in C

## Python

- [Build a Web Scraper](https://realpython.com/beautiful-soup-web-scraper-python/) - Scrape data from a website
- [Build a REST API](https://blog.miguelgrinberg.com/post/designing-a-restful-api-with-python-and-flask) - Flask REST API

## JavaScript

- [Build a Chat App](https://socket.io/get-started/chat/) - Real-time chat with Socket.io
- [Build a To-Do App](https://developer.mozilla.org/en-US/docs/Learn/Tools_and_testing/Client-side_JavaScript_frameworks) - MDN tutorial

## Java

- [Build a Spring Boot App](https://spring.io/guides/gs/spring-boot/) - Getting started
- [Build a REST Service](https://spring.io/guides/tutorials/rest/) - RESTful web service

## Go

- [Build a Web Server](https://golang.org/doc/articles/wiki/) - Wiki web app
- [Build a CLI Tool](https://github.com/spf13/cobra) - Cobra CLI library

## Rust

- [Build a Command Line App](https://doc.rust-lang.org/book/ch12-00-an-io-project.html) - I/O project
- [Build a Web Server](https://doc.rust-lang.org/book/ch20-00-final-project-a-web-server.html) - Multi-threaded web server

## Ruby

- [Build a Blog](https://guides.rubyonrails.org/getting_started.html) - Rails blog
- [Build a Gem](https://guides.rubygems.org/make-your-own-gem/) - Create your own gem
